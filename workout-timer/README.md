# 律动 · 运动计时器

直接用现代浏览器打开 `index.html` 即可使用，无需安装依赖、联网或构建。手机和桌面均可使用。

- 开始等待：默认 5 秒，可设 0–3600 秒。
- 运动时间：默认 30 秒，可设 1–3600 秒。
- 运动组数：默认 3 组，可设 1–100 组。
- 组间休息：默认 20 秒，可设 0–3600 秒。

所有设置为整数。点击“开始运动”后按“等待 → 运动 → 休息 → 下一组”自动计时，最后一组结束即完成。支持暂停、继续、重置和再来一次。重置保留已填写的配置并解除编辑锁定。默认总时长为 2 分 15 秒。

计时使用单调时钟计算经过时间，标签页恢复显示时会校准阶段。浏览器被系统挂起或设备锁屏时不能保证实时刷新；使用时请保持页面打开。本页面不含声音提醒。

## 容器预览与检查

在本目录运行：

```sh
docker compose up -d web
# 浏览器访问 http://localhost:8080
docker compose run --rm check
docker compose down
```

检查包括 JavaScript 语法及阶段边界、总时长、零等待/休息、单组、延迟刷新测试。纯静态页面没有编译步骤。
